Tipp: Unter Einstellungen → Bedienungshilfen → Gesprochene Inhalte → Stimmen eine "Enhanced"-Stimme herunterladen – klingt natürlicher. Die echte Siri-Stimme lässt Apple für Webseiten und Apps generell nicht zu.

Sterne-Verlauf

Für manuelle Korrekturen, z. B. wenn eine Belohnung außerhalb der App eingelöst wurde oder ihr euch auf einen Bonus geeinigt habt. Positive Zahl = Sterne dazu, negative Zahl = Sterne abziehen. Beides ist PIN-geschützt.

Automatischer Abgleich

Wird geprüft …
Einmal pro Gerät anmelden. Danach werden Vokabeln, Lernfortschritt und Sterne automatisch zwischen den Geräten abgeglichen.

Sicherungsdatei

Für den Fall, dass das Firebase-Projekt oder das Passwort verloren geht. Die Datei enthält alles: Units, Lernfortschritt, Sterne, Streak, PIN.
Noch keine Sicherung auf diesem Gerät.

Neue Unit hinzufügen

Format pro Zeile: Englisch;Deutsch
Beispiel: raccoon;der Waschbär
Eine Lautschrift in eckigen Klammern am Zeilenende wird ignoriert.

Zurücksetzen

Setzt sauber auf Null, ohne Eintrag im Verlauf. Die Vokabeln selbst bleiben in beiden Fällen erhalten.
